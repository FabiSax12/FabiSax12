**Computer Engineering student · Full-stack development, cloud infrastructure and AI agent engineering**

I'm looking for a software engineering internship in full-stack development, AI agent engineering and cloud infrastructure.

- 2+ years building web apps and cloud systems with Python, FastAPI, TypeScript, React and Next.js on AWS and Azure.
- Built a distributed processing platform on AWS (FastAPI, SQS, DynamoDB, Terraform).
- Maintain a production app used by TEC students, with automated tests, GitHub Actions CI/CD and Application Insights telemetry.
- Ship code with AI coding agents (Claude Code, MCP, Agent Skills) through a spec-driven workflow: written specs, scoped Jira tickets and human review of every change.
